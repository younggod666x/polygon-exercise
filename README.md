# Object-Oriented Polygon Art

Python turtle artwork built with a reusable `Polygon` class. The static program
draws 25 polygons; the animated program moves 18 polygons for 150 frames.

## Run locally

Requires Python 3 with Tkinter and a graphical desktop. Open a terminal in this folder.

```bash
python 05_polygon_art_starter.py
python 06_animated_polygon_art_starter.py
```

The first program creates static overlapping polygon artwork; the second
animates `Polygon` objects.

## Git milestones

- **Create static Polygon artwork:** `polygon_shape.py` and
  `05_polygon_art_starter.py` implement and draw the static composition.
- **Add animated Polygon artwork:** `06_animated_polygon_art_starter.py`
  animates the polygons while preserving the static program.
